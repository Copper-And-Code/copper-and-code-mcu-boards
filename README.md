# copper-and-code-mcu-boards

MicroPython + LVGL firmware for boards that upstream MicroPython does not cover, built as
out-of-tree boards and user C modules: no fork of MicroPython or of the LVGL binding
([PyDevices lvgl-micropython](https://github.com/PyDevices/lvgl-micropython), now
archived in favour of [omnipython-lvgl](https://github.com/PyDevices/omnipython-lvgl)).
All boards build on a pinned commit of omnipython-lvgl, unchanged; changes the sources
would need go in `patches/`, applied by the build script (none at the moment).

Every board ships a frozen `display_driver.py`, so `import display_driver` is all an
application needs, e.g. code generated by
[Copper and Code Studio](https://github.com/Copper-And-Code/copper-and-code-studio). The names it offers
(`WIDTH`, `HEIGHT`, `start()`, `stop()`, `running()`, ...) and what a Ctrl-C does are the
same on every board: [docs/display-driver.md](docs/display-driver.md).

## Build

```bash
scripts/build.sh <port> <BOARD> [VARIANT]   # pinned sources and toolchain in .work/,
                                            # patches/ applied, firmware in dist/
scripts/build.sh rp2 WAVESHARE_RP2350_TOUCH_LCD_4   # same as scripts/build_rp2.sh
scripts/build.sh stm32 STM32H7_CORE V13             # V10 or V13, the variant is required
scripts/build.sh esp32 ESP32_4848S040               # needs ESP-IDF v5.5.2, see scripts/build_esp32.sh
scripts/build.sh stm32 STM32F769_DISCO              # flash with st-flash (ST-LINK on the board)
```

Flashing an STM32 board over USB: [docs/flash-dfu.md](docs/flash-dfu.md). Over the UART
(ST bootloader): `scripts/stm32_uart_flash.py flash <file>.hex --verify`; use the script
of a commit after v0.1.5, the older one fails on images over 1 MB, which every STM32 image
since v0.1.5 is (`docs/stm32h743.md`, Bench).

## Layout

```text
boards/<port>/<BOARD>/   board definitions (BOARD_DIR)
modules/                 user C modules (rgbpanel: RGB panel scan-out with PIO + DMA;
                         st_ltdc: LTDC and DMA2D on the STM32H743, and MIPI-DSI on the F769;
                         esp_rgb: RGB panel on the ESP32-S3)
python/                  frozen drivers (display_driver.py, gt911.py, ui.py, buzzer.py)
examples/                small LVGL examples to run with mpremote
scripts/                 build scripts; UART flasher and script runner (STM32)
patches/<project>/       patches to the pinned external sources, applied by scripts/build.sh
tests/hil/               tests run on the board with mpremote; tests/host/ on the unix port
docs/                    measurements, logs (docs/log/), credits, upstream reports
hardware/                a printable box for the RP2350-Touch-LCD-4 (CadQuery, untested)
```
